Deep Equation Dive — Math Treasure Hunt

Overview

**Deep Equation Dive — Math Treasure Hunt** is a browser-based math adventure game where players solve equations to dive deeper into the ocean and unlock hidden treasure chests.

Players must solve mathematical problems correctly to progress through different ocean depth levels while managing lives and increasing their score.

The game is designed to make **learning math interactive and fun**, especially for students practicing algebra and basic arithmetic operations.

Gameplay

The goal of the game is to **solve equations and reach deeper ocean zones**.

Players start at the surface and move through multiple depth levels.

Each level presents **equations that must be solved correctly** to unlock treasure chests and progress further.

**Learning Objectives**
The game helps players practice:

* Addition
* Subtraction
* Multiplication
* Division
* Square roots
* Fractions
* Negative numbers
* Basic algebra

It encourages **problem-solving skills and mental math** through a fun exploration theme.

**How to Play**

1. Open the game in a web browser.
2. Click a treasure chest to start a math challenge.
3. Solve the equation using the on-screen math keyboard.
4. Press **ENTER** to submit your answer.
5. Correct answers allow you to dive deeper and earn points.
6. Be careful — wrong answers reduce your lives.

If all lives are lost, the dive ends.

**How to Run the Game**

### Run Locally

1. Download the repository.
2. Open the file:
index.html

3. The game will open automatically in your web browser.
